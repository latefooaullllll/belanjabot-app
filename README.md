
# BelanjaBot

BelanjaBot adalah chatbot berbasis Python dan Flask untuk membantu pengguna mendapatkan informasi seputar belanja melalui percakapan interaktif dengan metode rule-based.

## Fitur Utama
- Chatbot interaktif
- Mode belajar seputar belanja
- Kalkulator belanja
- Riwayat percakapan
- Evaluasi dan pengujian chatbot

## Teknologi
- Python
- Flask
- HTML
- CSS
- JavaScript

## Struktur Folder
- `chatbot/` – Logika dan mesin chatbot
- `evaluasi/` – Dataset evaluasi
- `static/` – CSS dan JavaScript
- `templates/` – Halaman aplikasi
- `tests/` – Pengujian aplikasi
- `themes/` – Data intent chatbot
- `screenshots/` – Dokumentasi hasil aplikasi

## Screenshot Aplikasi

Lihat hasil tampilan dan percakapan BelanjaBot pada folder [screenshots](screenshots/).

## Cara Menjalankan

1. Clone repository.
2. Install dependency dengan `pip install -r requirements.txt`.
3. Jalankan aplikasi dengan `python app.py`.
4. Buka alamat lokal yang ditampilkan Flask di browser.
